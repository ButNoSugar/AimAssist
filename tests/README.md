# Тесты

```
python tests/run.py        # все наборы
python tests/run.py -v     # с полным выводом
```

Нужны только `numpy` и `opencv-python-headless`. Остальное — `pyautogui`,
`keyboard`, `mss`, `tkinter`, `PIL` и весь WinAPI — подменяется заглушками из
`tests/stubs/sitecustomize.py`, которые подкладываются через `PYTHONPATH`.
Поэтому наборы идут и на Linux, где настоящих вызовов Windows нет.

| набор | что проверяет |
|---|---|
| `test_bootstrap.py` | поиск venv и перезапуск через него, объяснение вместо стектрейса, удержание консоли. **Только POSIX** — подменяет интерпретатор shell-скриптом |
| `test_startup.py` | старт целиком: конфиг, профили, наведение, проверка платформы, деградация оверлея |
| `test_console.py` | живая строка, приглашение, ширина меню, оба способа стирания строки |
| `test_color_and_help.py` | включение ANSI, режимы `color`, цвет по бюджету кадра, подробные описания |

Заглушки умеют притворяться разным окружением: `WIN` задаёт окно игры и
копит инъекции `SendInput`, `_K32.VT_OK` отключает поддержку ANSI,
`_K32.TICKS` эмулирует перезагрузку компьютера, `AIMTRACKER_TEST_EXIT_AFTER`
выводит главный цикл из подпроцесса.
